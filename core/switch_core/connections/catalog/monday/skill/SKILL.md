# Monday.com

Discover the available tools and inspect the target board's schema before
reading or changing items. Match boards and items by stable identifiers;
ask when a name has several matches. Check column types and allowed values
rather than guessing their representations.

Read the current item before updating it. Keep writes focused on the
requested columns, and preserve unaffected values. Confirm with the user
before archiving or deleting items, removing groups, or changing column
definitions.

Summarize results concisely, noting board names, item names and links so
collaborators can locate changes in Monday.com.
